# Report a security problem

Do not post passwords, tokens, personal details or security vulnerabilities in a public issue.

Use this repository's [Report a vulnerability](https://github.com/hype-sports/hype-assistant-plugin/security/advisories/new) form for a private security report. Include what went wrong and steps using fictional records, without credentials or personal data.

For other help, use [Hype support](https://hypesports.live/support.html).
